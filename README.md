# FrameFind

FrameFind is an image-search interface designed to help users discover images by entering a topic into a simple search box. The current version focuses on the search interface and responsive results layout, while image fetching will be added in Part 2.

The design uses a warm cream and orange colour theme instead of the reference design's colours. A sticky header keeps the search controls visible while scrolling, and quick-search category chips make common search topics easy to discover.

## Design Decisions

The warm cream, dark charcoal, and orange colour palette gives the application a distinct visual identity.

A row of quick-search chips for Nature, Cities, and Animals was added to make common searches easy to access.

The results area uses CSS Grid with auto-fill so the layout automatically adapts to different screen sizes.

## Part 1

This version provides the initial responsive search interface. Image results and search functionality will be added in Part 2.
